## Publish with GitHub Pages
1. Sign in to the GitHub account `parvezpathan1987`.
2. Create a **public** repository named `parvezpathan1987.github.io`.
3. Upload the contents of this folder (not the ZIP file) so `index.html` is at the repository root.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. After deployment, the site should be available at `https://parvezpathan1987.github.io/`.
